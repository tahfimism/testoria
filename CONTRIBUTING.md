# Contributing

**Note:** This repository currently contains the **build artifacts** (compiled HTML, CSS, and JavaScript) of the AI Quiz Maker application, rather than the original source code.

## Modifying the Application

Because the source code (`src/` directory, `.jsx` files, etc.) is not present, standard development workflows (like `npm run dev`) are not applicable.

The `assets/` directory contains minified code generated by Vite.

## Reporting Issues

If you encounter bugs or have feature requests, please open an issue in the issue tracker.
